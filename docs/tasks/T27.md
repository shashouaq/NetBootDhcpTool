# T27 合并网卡状态刷新并校验返回身份

类型：运行效率与异步状态一致性；优先级：P2；风险：中；接手：Luna。状态见[待办索引](../TODO.md)。

## 目标与源码证据

降低重复只读枚举开销，并保证异步读取只更新发起该请求的当前网卡。

- 基线同 T20。[MainWindow.RefreshSelectedAdapterStatus](../../src/NetBootDhcpTool.App/MainWindow.xaml.cs) 由 3 秒计时器和两个 NetworkChange 事件触发；现有防重入只跳过正在运行时的重复调用。
- 该方法每次调用 `GetAdapters(false)` 枚举并构建全部网卡，再按 interface index 找一条；await 后也仅检查 index。切换接口、index 复用或读取期间开始系统操作时，需要更明确的返回有效性判断。
- [NetworkAdapterService.GetAdapters](../../src/NetBootDhcpTool.Network/NetworkAdapterService.cs) 的 IPv4 属性异常分支会通过 `TryFindNetAdapterIndex` 再次全量枚举；该方法仍按名称重复获取相同 IPv4 属性。不能将名字当稳定身份兜底。

## 实现范围与步骤

1. 提取可测试的只读刷新协调器，统一计时器、网络变化事件和选择变化入口。网络事件在 250 ms 窗口内合并，最多一个在途读取；读取期间收到变化只置 dirty，结束后最多补一次最新请求。
2. 每次请求捕获稳定 `NetworkInterface.Id`、当前 index 和选择/工作流代次。提交前再次验证选择、ID/index、代次、关闭状态和网络工作流状态；不一致则丢弃结果，不向新对象复制字段。
3. 保留 3 秒兜底刷新和用户主动刷新；后者继续获取完整当前网卡/路由。背景选中网卡刷新只读取所需网卡详情，同轮至多一次基础枚举；异常接口记录原因后跳过，不靠二次按名称查询猜身份。
4. 刷新字段比较覆盖实际显示的状态、地址、网关、MAC、链路速率及相关详情；只有发生变化才更新 UI。无变化轮次不重建下拉列表、不追加 IP 历史。
5. 网络工作流开始即使旧读取失效；工作流结束使用现有内部读回更新。关闭取消后观察在途任务，迟到结果不触发历史保存或声音。没有可取消底层 API 时明确停止接收结果，不能谎称已中断 OS 枚举。

## 边界与非目标

- 不缓存写前验证结果，不把后台显示快照用于 DHCP/MAC/路由恢复授权；原稳定身份和实时归属检查仍在服务侧执行。
- 不改变 WLAN、虚拟/断开接口的产品规则；全量刷新继续展示全部可枚举接口。
- 不改变 NetworkInterface 属性异常时跳过相应接口的规则，不将刷新失败显示为网卡必然消失。

## 验收标准

- [x] 测试时钟下，同一合并窗口 100 个事件只触发一次读取；读取期间再出现事件至多补一次，永远只有一个在途读取。
- [x] 无变化兜底读取不会产生列表重建/历史保存；每轮基础枚举不重复，手动全量刷新保持完整。
- [x] 延迟返回期间切换 A→B、相同 index 换 GUID、开始工作流或关闭窗口，旧结果均不更新 UI/历史。
- [x] 网络变化后按合并窗口及时请求，漏事件时仍有 3 秒兜底；只改变 MAC 或速率也正确更新显示。
- [x] T20 给出事件洪峰读取次数和空闲阶段 CPU/分配样本，不把去抖延迟隐瞒为无成本提速。

## 实施证据 / 2026-09-27

- 协调器单测使用受控挂起读取验证 100 次事件只产生一次最新补读、最多一个在途读取；T20 为 101 次事件保留了五个样本，实际读取数均为 2。
- 非管理员 UI smoke 覆盖 A→B→A 后丢弃旧代次、同 interface index 换 ID、工作流期间与窗口关闭期间丢弃结果；对无变化快照核验不触发列表集合刷新或 IP 历史写入，对有效变更核验 MAC/速率显示更新。
- UI smoke 还运行了 101 次网络变化事件、验证 250 ms 安静窗口重启和 3 秒兜底计时器设置；没有通过禁用网卡制造事件。最终 T20 报告中，100,000 次未变化字段比较的中位耗时 `0.36 ms`，CPU 计时低于采样分辨率，分配量中位数 `63,544` 字节。该数值仅表示比较路径。
- UI smoke 在合成门禁下调用完整刷新入口，并与前后两次当前主机只读枚举比较；本轮读回 5 个适配器、57 条 IPv4/IPv6 路由，前后适配器和路由集合一致。
- 当前主机只读全量/定向身份刷新各 5 次，中位数 `19.2/18.8 ms`；没有可见墙钟优势，也没有放宽稳定 ID/index 返回校验。
