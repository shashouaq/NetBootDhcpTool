# T13 方案字段加载、显示与对比

类型：业务完整性；风险：中；追溯：BIZ-004、TEST-003、TEST-004、MAINT-002。状态见 [待办索引](../TODO.md)。

## 目标与当前问题

保存、加载、编辑、对比、预览和实际执行使用同一组有效方案字段，不隐藏已生效值或错误报告“完全一致”。

- 证据：[MainWindow.LoadProfileIntoForms](../../src/NetBootDhcpTool.App/MainWindow.xaml.cs) 填入 DhcpGateway/DhcpDns 后仅显示标签；[XAML](../../src/NetBootDhcpTool.App/MainWindow.xaml) 的输入框原为 Collapsed，隔离复现有值仍隐藏。
- `CompareProfile_Click` 比较 IP、掩码、池等，却遗漏 Gateway、Dns、LeaseSeconds；仅这些字段不同时也可能显示“完全一致”。启动预览能展示相关值，不能把问题描述成全部流程均隐藏。
- [ProfileStore](../../src/NetBootDhcpTool.Core/ProfileStore.cs) 与 [NetworkProfile](../../src/NetBootDhcpTool.Core/Models.cs) 已包含字段；导入、表单和执行前校验也应对齐。

## 实现范围

允许修改主窗口方案捕获/加载/比较/导入验证、ProfileEditor 的必要交互、现有方案模型兼容、相关本地化及测试。

边界：加载方案只填表单，不直接应用网络；保留旧 JSON 字段与路由身份重定位规则；计算型路由跃点不得伪装成固定用户输入。非目标：新方案类型、自动执行、全面配置格式迁移或调整 DHCP 参数业务范围。

## 业务规则与实现要求

- 有效非空网关/DNS 加载后标签和输入框均可见可编辑，相应“添加字段”按钮状态一致；空值、切换方案及手动清空时不保留隐藏旧值。
- 比较涵盖所有会影响 DHCP、手动扫描及路由执行的持久字段，包括网关、DNS、租期；对空值、IP/前缀规范化和路由集合采用稳定语义。
- 对比确实没有有效差异才显示“完全一致”；不要以 HashSet 意外掩盖非法重复路由，重复项在校验中明确拒绝。
- 导入预览、保存/加载和执行前分别说明草稿/有效配置状态；应用必须复用 DHCP/路由校验及 T11 扫描校验，不能只检查能否解析字符串。
- UI 只对通过校验的有效值建立执行预览；DHCP 运行时加载/修改遵守 T03，不能静默改变正在运行服务的配置。

## 验收标准

- [x] 单独改变 Gateway、Dns、LeaseSeconds 任一项，均能列出正确差异；反复保存/加载后值一致。
- [x] 加载非空隐藏字段后可见可改；加载空值方案不会继续使用上一方案的网关/DNS。
- [x] 导入旧格式、有缺省字段、非法地址池/租期/路由和扫描范围时有明确结果，预览与实际校验一致。
- [x] 加载不写系统，复制保留内容但生成独立身份；取消操作不修改原方案。

## 测试与回归要求

- 用表驱动单测逐字段验证捕获→保存→加载→比较，以及空值/规范化/重复路由边界；采用临时文件验证旧 JSON 往返。
- 增加 WPF 行为测试验证字段 Visibility、Text、添加按钮和对比内容，不只检查控件存在；网络调用使用替身。
- 回归方案保存、复制、编辑、导入导出、删除、DHCP 预览/启动、手动扫描和路由方案预览；双语与 900×560 DIP 布局不退化。
