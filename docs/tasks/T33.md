## 现状与范围

MainWindow 同时持有日志队列、同步锁、省略计数与关闭标记，负责后台日志事件和 UI 定时器之间的并发边界。提取不依赖 WPF 的 `LogDisplayBuffer`，统一管理入队、积压裁剪、批量读取、清空、省略计数和关闭。窗口保留可见性、定时器、RichTextBox 渲染、颜色、滚动与双语提示。

保留积压/显示各 500 条、普通批次最多 128 条、强制读取用于展开/关闭，以及关闭后拒绝新行但允许读取已有行的行为。文件日志仍由 FileLogger 完整写入。不是全窗口重构，不改网络、恢复、安装或更新协议，不承诺性能提速。
