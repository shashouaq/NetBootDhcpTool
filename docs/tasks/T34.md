# T34 DHCP 与固定 IP 对端连通状态持续显示

类型：用户体验与状态一致性；优先级：P1；风险：中。状态只见 [TODO](../TODO.md)。2026-10-06 用户授权显示“已连通、已离线”等变化。

## 已确认问题与实施范围

DHCP StatusText 仅表示 Assigned/Released 等协议状态；周期 Ping 已更新，但状态列仍显示已分配。固定 IP 单目标在首次 Ping 成功后停止循环；离线结果仍可能被 Assigned override 遮盖。

增加独立连通状态、最后检查/变化时间和颜色；保留租约协议状态。固定 IP 已知结果持续进行有界 Ping 探测，复用已有协调器（最多 8 并发、64 待执行），轮转已知结果，不扩展扫描网段。每两秒安排有限批次；大量结果的整轮延迟单独说明。

重扫、恢复网卡、切换适配器或关闭时取消/失效旧监测，迟到结果不得复活旧行。仅 Ping 的离线表示未收到响应；不使用旧 HTTP 结果冒充当前可达。不改变 DHCP ACK、租约有效期、恢复日志或真实网卡配置顺序。

## 验收

纯状态与注入探测测试覆盖待探测→连通→离线→重新连通、终态/历史租约、同 IP 换持有者、固定 IP 监测取消和迟到结果；WPF UI 验证绑定、状态颜色和时间。运行 pinned SDK 完整构建、MSTest、控制台/UI、维护检查和文档检查。不以模拟测试代替真实对端断线实测。

## 2026-10-06 本地实现与证据

Core `PeerConnectivity` 记录待探测、已联通、已离线、已停止监测及最近检查/变化时间，重复同状态探测仅更新检查时间。DHCP 独立显示连通列，协议状态和最后上线时间保留；终态/历史行停止监测，不接收迟到结果。单目标第一次失败即可显示离线；首次成功后，单目标及网段已发现对端均继续监测。

固定 IP 监测独立复用 `LeaseProbeCoordinator`（8 并发、64 待执行），每两秒轮转最多 32 个已知结果；不重新枚举网段。少量对端通常每两秒安排一次；4096 个已知结果仅安排一轮就需约 256 秒，最近探测时间明确表示样本年龄，不承诺全部两秒更新。新扫描冻结配置 IP；停止扫描、网卡恢复/重启/MAC/回滚、切换适配器与关闭都失效旧会话；其他工作流暂停调度。离线清除旧网页标志；重新联通只确认 Ping，网页详情仍需重新扫描。CSV 导出增加连通状态与时间，先在 UI 线程取得快照；从未联通的手动对端不生成假最后联通时间。
