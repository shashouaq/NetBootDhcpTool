# T12 收藏生命周期和无密码导出

类型：业务完整性；风险：中高；追溯：BIZ-003、TEST-003。状态见 [待办索引](../TODO.md)。

## 目标与当前问题

收藏可以持续删除、原位编辑和重录凭据；导入不隐式丢失本地信息，“不含密码”导出必须移除全部密码字段。

- 证据：[Defaults.EnsureFiles](../../src/NetBootDhcpTool.Core/Defaults.cs) 每次补回删除的预设，且符合旧预设标记时反复覆盖描述/备注等；删除后重启复活已用合成数据复现。
- [MainWindow.MergeFavorite](../../src/NetBootDhcpTool.App/MainWindow.xaml.cs) 以导入空字段覆盖本地备注、自定义字段和密码，已复现；列表只读且详情无完整编辑已有记录入口，解密失败提示重录却无法直接闭环。
- [FavoriteStore.SaveCredentialFreeExport](../../src/NetBootDhcpTool.Core/FavoriteStore.cs) 保留 `PublicPassword`，合成公共默认密码仍进入导出。未发现实际个人密码泄漏证据，不能混同。

## 实现范围

允许修改收藏弹窗/列表命令、合并与去重、默认预设迁移/删除标记、FavoriteStore 及必要模型、帮助/本地化和测试。定位 [FavoriteWindow](../../src/NetBootDhcpTool.App/FavoriteWindow.xaml.cs)、[FavoriteConfig](../../src/NetBootDhcpTool.Core/Models.cs)。

边界：保留只读 DataGrid 的计算列绑定、DPAPI 和已标明的厂商公共默认值；“加载配置”不触发系统写入，“应用并扫描”仅执行一次。非目标：云同步、密码管理器、猜测厂商凭据或扩充厂商库。

## 业务规则与实现要求

- 编辑使用副本，确认后保留原 ID 并更新记录；取消不改变原对象。支持解密不可用时替换密码或明确清空，不丢失设备备注。
- 公共预设删除后持久记录删除意图；启动/升级不复活，提供独立确认的“恢复内置预设”。迁移仅更新未被用户修改的默认内容，不能反复覆盖本地信息。
- 导入沿用 ID 优先、必要时语义去重；空/缺失可选字段默认保留本地值。显式清空只通过编辑确认，本任务不让旧导入文件的空字段代表清空。
- 自定义字段按稳定键合并，保留导入未涉及的本地字段；冲突值及凭据是否替换在导入预览中明确列出，确认后一次保存。
- 普通个人凭据始终 DPAPI；外部文件不能仅凭 `IsPublicDefault=true` 将任意个人密码降为明文。编辑公共预设密码为个人值时转为个人凭据存储。
- 无密码导出必须清空 Password、ProtectedPassword、PublicPassword 及其他凭据载荷，不导出可解密密文；公共默认密码也不例外。

## 验收标准

- [x] 已有记录可编辑、重录、显式清空；取消保持原数据；ID、使用记录与未编辑字段不丢失。
- [x] 删除内置预设后重启/初始化不复活，明确恢复操作可重建，升级不覆盖用户备注。
- [x] 重复导入不产生第二条同义记录；空字段不擦掉本地值，自定义字段不整表替换，导入预览与最终结果一致。
- [x] 个人/公共/解密失败三类记录的无密码导出均不含任何密码字段内容；重新导入不把本地密码清空。
- [x] 在第二个 Windows 用户身份下用合成凭据验证 DPAPI 密文不可跨用户解密；界面保留非凭据数据并允许重录或显式清空凭据。
