## 范围与约束

新增地址管理页：全量地址只读展示、业务/带外标签、追加草稿、预览/应用/逐条移除/恢复、临时 ActiveStore 地址、方案保存/加载、指定源地址的 Ping/HTTP 探测与持续状态。原隔离替换模式保留；追加模式不得清空业务地址、默认路由、DNS、跃点，禁止 WLAN 写入。稳定网卡 ID 唯一解析，写前即时记录意图，读回验证；仅清理已确认本工具拥有的地址。未知结果、外部改动和地址属性不匹配保留恢复项，不整份覆盖旧快照。

支持 DHCP 客户端地址与固定地址共存：能力检测并读取原共存开关，不能识别原状态时拒绝写入；使用 netsh IPv4 地址追加并读回 DHCP/默认路由/DNS/跃点。最后一条所属地址清理后恢复由本工具改变的开关；原开关已启用时保留。恢复中心提供独立条目，启动不自动写网络。

多地址模式下原 DHCP 服务仍只有一个明确作用域，仅用于隔离链路。追加/复用选定服务器地址、保留其他固定地址；共享业务 DHCP 广播域不支持启动工具 DHCP。不可用多 IP 替代 VLAN 隔离或自动区分两个池。旧替换/完整恢复责任与新精确追加责任不得同时覆盖同一网卡。
